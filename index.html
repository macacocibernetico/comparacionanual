⚙️ Configurar planillas

🔒 Todo se guarda solo en este navegador. No queda en el código ni en GitHub, así el repositorio público nunca expone tus datos.

💡 Si la planilla está compartida como “cualquiera con el enlace: lector”, el dashboard la lee sola. La comparte solo quien tenga la URL.

Escribí el nombre exacto del encabezado que usa esta planilla para cada dato. Sirve para que cada negocio pueda tener nombres distintos. No importan mayúsculas ni acentos; si lo dejás vacío se usa el nombre por defecto.
